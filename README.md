# AI HUB NEXUS

A responsive dark violet premium UI prototype for a Telegram Mini App.

## Included
- AI Chat, AI Writer, Translator, Documents, Image Studio interface
- English default with English, Russian and Uzbek interface demos
- Weekly $9.99, Monthly Pro $24.99, Yearly VIP $99.99 plan cards
- Responsive desktop/mobile layout

## Important
This is a front-end prototype only. AI responses, document processing, image generation, Supabase, Telegram authentication and payment processing are NOT connected yet. Do not accept payments until these are implemented and tested.

## Run locally
```bash
npm install
npm run dev
```
